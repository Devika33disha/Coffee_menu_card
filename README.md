# Coffee Shop Billing System with Cart

A simple Python mini project built using Object-Oriented Programming (OOP).

This project simulates a coffee shop billing system where a user can:
- enter their name,
- choose multiple types of coffee,
- add items to a cart,
- enter valid quantities,
- and get a final bill with 2% GST.

After completing one order, the program starts again for the next customer.

## Features

- 5 coffee items in the menu
- User name input
- Cart system for multiple coffee orders
- Quantity validation (no zero or negative values)
- Automatic bill generation
- 2% GST calculation
- Thank you message for the customer
- Repeats for the next customer

## OOP Concepts Used

- Classes and Objects
- Constructors
- Methods
- Lists for storing objects
- Object interaction between menu, cart, and billing system

## Project Structure

- `Coffee` class → stores coffee name and price
- `CartItem` class → stores selected coffee and quantity
- `CoffeeShop` class → manages menu, cart, input validation, and bill generation


## Sample Workflow

- Enter customer name
- Select coffee from menu
- Enter quantity
- Add more items if needed
- View final bill with GST
- Program restarts for the next customer

## Learning Outcome

This project helped me understand how OOP can be used to build a simple real-world billing system using Python.
